HexoPress 的 AI 面板不是一个独立聊天窗口，而是和编辑器深度联动的写作助手。它会读取当前文章的正文、选中文本和元信息，因此更适合边写边改，而不是脱离上下文单独提问。

## 先配置模型提供商

进入「设置」→「AI」标签页，先添加至少一个提供商。当前需要填写的字段包括：

- 名称
- API 端点
- API Key
- API 规范（当前为 OpenAI Compatible）
- 模型 ID

你可以同时配置多个提供商，例如云端模型和本地代理模型，然后在编辑器里按任务切换。

> 插图：请插入 AI 设置页截图，展示提供商卡片和模型 ID 输入框

## 打开 AI 面板

在编辑器右侧点击 AI 图标，即可展开 AI 面板。面板由三部分组成：

- 顶部预设按钮
- 中间消息区
- 底部输入栏和模型选择器

输入栏会显示当前选择的提供商，并在旁边展示实际使用的模型 ID。

## 四个内置预设

当前内置了四个高频预设：

### 错别字检查

以全文为上下文，检查错别字、语病、标点和表达问题。

### 写作建议

以全文为上下文，从结构、逻辑、表达和可读性几个维度给出改进建议。

### 段落润色

以当前选中的文本为上下文，只处理你框选出来的那一段内容。如果没有选中文本，HexoPress 会先提示你选择内容。

### 生成摘要

以全文为上下文，生成适合 excerpt、SEO description 或社交平台预览的简洁摘要。

> 插图：请插入 AI 面板截图，展示四个预设按钮和消息区

## 上下文是自动感知的

AI 面板不需要你每次手动选择模式。它会根据当前编辑状态自动决定上下文：

- 有选区时，优先使用选区
- 没有选区时，默认使用全文
- 如果你点击上下文条上的关闭按钮，则本轮对话改为无上下文

这意味着你在编辑器里框选一段话之后，AI 面板就会自然切换到“更像局部改写器”的工作方式。

## 自由对话

除了预设，你也可以直接在输入框里输入自己的问题，例如：

- 帮我把这段改得更口语一点
- 这篇文章的结构还有什么问题
- 给这篇文章拟 5 个更像标题党的标题

回复会以流式方式逐步显示在消息区，便于你边看边判断是否继续追问。

## 适合什么场景

HexoPress 的 AI 写作助手特别适合这些场景：

- 写完初稿后做一次结构和表达巡检
- 对选中的一小段进行局部润色
- 快速生成摘要、导语或社交分享文案
- 在不中断写作界面的前提下，和 AI 讨论文章方向

如果你希望 AI 参与的是“开发过程”而不是“写作过程”，可以继续阅读《AI 协作开发与 OpenSpec 工作流》。
